# Warkworth grocery price check

Daily comparison of key grocery staples across the three Warkworth (Auckland, NZ) supermarket stores:

- **Woolworths Warkworth** (20–24 Neville St)
- **New World Warkworth** (6 Percy St)
- **PAK'nSAVE Warkworth** (12 Hudson Rd)

[**Open the live page →**](https://sjurgis.github.io/warkworth-grocery/)

The page shows the cheapest store per item (by unit price), specials / Clubcard prices, a reference basket total per store, and day-on-day price changes. It is regenerated each morning from the stores' own public online catalogues. Unofficial — not affiliated with Woolworths, Foodstuffs, New World or PAK'nSAVE.
